# Tech stack we are going to be using:
* Typescript
* Tailwind CSS
* React Framework
* ShadCN UI

# Some important rules to follow
* All code should be optimized for performance
* All code should be explanatory
* If some code is tough then you will write comments for that code (not every code needs to be commented)
* On top of every file we write what that particular file does
* No extra code ever. We do not need any extra code.
* Most important point of all. Always write simple code. Simple is better.
* API connections should be all written in a seperate folder named API.
* Try to make required changes in minimum number of lines of code.

# Design rules
* Always use ShadCN UI to reduce burden for creating every component.
* Follow the color theme.
* Our websites design style will be a minimalist dev tool.
* We need to make sure its functional and gets the job done.
* While designing the frontend always keep the backend in mind.
