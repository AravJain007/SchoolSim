# Target Audience for the commit message

- Young professionals learning about project building and management.
- Students who want to implement this project in their respective universities.

# Way of writing:

- At the begining of the sentence always add a New Feature or Fix so that the person knows what is going on.
- There should be only one line per feature, fix or refactor.
- The one sentence should be easy to understand and in a simple language.

# Format:

One line description of all the changes in the code.

Backend: (if any)

- Fix/Feature/Refactor: One line description
- Fix/Feature/Refactor: One line description

Frontend: (if any)

- Fix/Feature/Refactor: One line description
- Fix/Feature/Refactor: One line description
