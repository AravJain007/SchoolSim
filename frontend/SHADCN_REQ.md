# Required ShadCN Components

Please install the following components using `npx shadcn@latest add ...` or your preferred method.

```bash
npx shadcn@latest add button card input label select slider separator scroll-area badge progress tooltip sheet dialog
```

## List of Components
- `button`
- `card`
- `input`
- `label`
- `select`
- `slider`
- `separator`
- `scroll-area`
- `badge`
- `progress`
- `tooltip`
- `sheet` (optional, for mobile menu if needed)
- `dialog` (for modals if needed)
